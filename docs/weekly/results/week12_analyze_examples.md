# 질문 분석 지시문: 지역 정책만 규칙 정리(v10)와 예시 줄이기 측정 (11-23)

## 요약
- `analyze_v10`: 지역 정책만(`local_only`) 판단을 "정책을 하는 곳 / 사는 곳" 기준의 순서 규칙으로 정리. 사는 곳만 말한 질문이 가끔 전국 정책을 빼던 문제를 고침
- 예시 줄이기: 예시를 줄이면 분석이 약 0.3초 빨라지지만, 지시문 작성에 쓰지 않은 질문에서 약 4% 틀려 **줄이지 않고 v10 유지**
- v9 지시문은 남김

## 1. 지역 정책만 규칙 (v9 → v10)
v9는 틀린 사례마다 한 줄씩 붙인 다섯 줄이라 "분야 없이 지역 → true"와 "사는 곳 → false"가 부딪힘. "제주에 사는데 청년 지원 뭐 있어?"처럼 사는 곳만 말하고 다른 조건이 없으면 가끔 true가 되어 받을 수 있는 전국 정책이 빠짐.

v10은 위에서부터 보고 처음 맞는 것을 씀. 헷갈리면 false (잘못 false면 전국 정책이 남고 지역 정책 앞세우기는 그대로라 덜 해로움)

| 순서 | 조건 | 결과 | 예 |
|---|---|---|---|
| 1 | 한정하는 말 ("만", "전국 말고") | true | "인천만", "포항 사는데 포항시 정책만" |
| 2 | 분야·지원 종류를 말함 | false | "인천 청년 주거 지원" |
| 3 | 사는 곳 ("~ 사는데", "거주", "~에서 받을 수 있는") | false | "원주 사는 사람인데 청년 정책 뭐 있어?" |
| 4 | 분야 없이 그 지역에서 하는 정책 | true | "인천 청년 정책 뭐 있어?", "청주시에서 운영하는 청년 지원" |
| 5 | 그 밖 | false | |

| 확인 | v9 | v10 |
|---|---|---|
| 사는 곳만 말한 질문 6개 × 3회 (분석만) | 2번 틀림 | 18/18 |
| 정책을 하는 곳 9개 · 사는 곳 3개 · 둘 다 1개 × 3회 | - | 모두 맞음 (확인 15개 45/45) |
| 지역 정책만 회귀 24개 × 2회 (전체 파이프라인, 인천 부평구) | 0/24 틀림 | 0/24 틀림 |

- v10 첫 안("지역이 정책을 꾸미면 true")은 회귀에서 "인천 청년 주거 지원", "인천 창업 지원금"을 true로 바꿔 2개 틀림 → 분야를 먼저 보는 순서 규칙으로 고침
- 규칙에 넣은 예는 확인 질문과 겹치지 않는 지역 이름(여수, 세종, 강릉)으로 씀

## 2. 예시 줄이기 측정
### 왜
v10 입력 약 1만 토큰 중 예시 34개가 약 70%. 일반 권장(예시 3~5개)보다 훨씬 많고, 게이트웨이(Bedrock 경유)가 앞부분 캐싱을 하지 않아 캐시로 줄일 수도 없음. 정확도가 같을 때만 줄이기로 함

### 방법
- 규칙은 모두 v10, 예시 수만 다른 지시문 3개를 같은 입력으로 분석만 부름. 질문마다 세 지시문을 동시에 불러 시간대 차이가 섞이지 않게 함

| 지시문 | 예시 | 글자 수 |
|---|---|---|
| 전체 (v10) | 34개 | 21,741 |
| 줄임 | 9개 (규칙만으로 헷갈려 예시를 넣게 된 경우를 묶음마다 하나: 마감 제외, 비교 대상, 번호 지목, 긴 사연형, 지목 비교, 정책 대화 중 용어, 현재 정책 둘, 사용자 조건, "인천만") | 11,421 |
| 없음 | 0개 | 6,806 |

- **시험 세트** 44개 × 3회: 지시문 예시와 개발 세트에 쓰지 않은 정책 이름·맥락·말투로 새로 만들고, 돌리기 전에 정답을 정함 ([week12_analyze_test_set.json](week12_analyze_test_set.json)). 맥락 5개(대화 없음, 교육 목록 뒤, 저축 상세 뒤, 현재 정책 둘, 월세 목록 뒤)
- **개발 세트** 69개 × 1회: 10주차 분석 세트(기본 19, 용어 12, 관계없는 용어 6), 비교 세트 17, 지역 정책만 확인 15. 지시문을 만들 때 쓴 질문이라 전체(v10)에 유리함 → 이미 고친 경우가 다시 틀리지 않는지만 봄
- 질문마다 정답에 적은 칸(의도, 지목, 비교 대상 수, 지역 정책만, 신청 상태, 분야, 화제 전환, 하위 질문 수, 사용자 조건)이 모두 맞아야 맞음
- 판단 기준 (모두 만족해야 줄임): 시험 세트 맞은 수가 전체보다 적지 않음, 개발 세트에 새로 틀린 질문 없음, 분석 시간 중앙값 0.2초 이상 감소

- 줄임이 틀린 2개: "K-패스가 뭐야?"를 범위 밖으로(정책 이름을 일반 용어로 봄), "원주 사는 사람인데 청년 정책 뭐 있어?"를 지역 정책만으로 (1절에서 고친 경우)
- 전체가 틀린 2개는 정답 쪽 문제일 수 있음 (아래 관찰)

### 판단
- 줄이면 분석 약 0.3초·입력 토큰 40~60% 감소. 그러나 처음 보는 질문에서 전체 0번, 줄임·없음 각 5번(약 4%) 틀리고, 틀리는 내용이 처리 경로를 바꿈 (목록 → 자격, 되묻기 → 단정, 비교 대상 수) → 기준 미달로 **v10 유지**
- 예시가 없으면 추론 토큰이 오히려 늘어(35 → 40) 예시가 판단을 덜어 주는 것으로 보임
- "없음"에 규칙을 보강하는 방법도 있지만, 이번 결과를 보고 고치면 시험 세트에 맞추는 것이라 새 시험 세트가 필요함. 0.3초에 비해 비용이 커 하지 않음

## 관찰 (이번에 안 고침)
- 현재 정책이 둘일 때("1번이랑 2번 자세히 알려줘" 다음) "신청 기간은?", "중위소득이 뭐야?": 10주차 정답은 되묻기인데 v10 전체는 1회 측정에서 두 정책 모두의 상세로 봄. 방금 둘을 같이 물었으니 둘 다 답하는 것도 자연스러워, 정답을 어느 쪽으로 둘지 정해야 함
- 시험 세트는 앞으로 지시문을 바꿀 때 다시 쓸 수 있음. 이번 결과를 보고 지시문을 고치지 않았으므로 아직 시험용으로 유효함
