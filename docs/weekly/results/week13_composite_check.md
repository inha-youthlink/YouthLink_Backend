## 5. 알려진 한계 (이번에 안 고침)

- **분석이 나누지 않으면 지금까지처럼 처리**: 3절. 분석 지시문을 바꾸는 일이라 PR 1 범위 밖. PR 2(`analyze_v11`) 때 나뉘는 비율을 같이 본다
- **한 하위 질문에 두 주제가 섞임** (C02): 분석이 첫 하위 질문을 "창업 지원금과 마음 건강 상담"으로 만들어 창업 카드가 하나뿐
- **복합 안의 비교는 답하지 않음**: 대상별 카드 규칙이 복합 카드 규칙과 겹쳐 조건이 계속 늘어 "따로 물어봐 주세요"로 안내함 (`design.md` 8-5). 비교는 단일 질문으로 처리됨
- **문장이 어색한 경우**: 가리킨 정책의 답을 목록 앞에서 한 번 더 말함 (C06), 질문 문장 한 줄을 그대로 옮김 (C08), 넷째 질문 안내가 마무리 문장 뒤에 붙음 (C16). 사실이 틀리지는 않음
- **카드는 묶음마다 1개 이상을 코드가 보장**: 한 묶음의 후보가 모두 질문과 무관하면 무관한 1위가 카드로 나올 수 있음 (수정 전 C03). 지역 정렬 수정 뒤에는 관찰되지 않음
